# Руководство svn-precommit-review

`svn-precommit-review` — это навык Codex Agent для проверки рабочей копии SVN/TortoiseSVN перед коммитом и создания сообщения коммита на корейском языке. По умолчанию он работает только на чтение. По явному запросу на CLI-коммит Codex может безопасно add необходимые новые исходные файлы и после одного финального подтверждения закоммитить только одобренную область.

## Установка

```text
%USERPROFILE%\.codex\skills\svn-precommit-review\SKILL.md
```

или:

```text
<project-root>\.agents\skills\svn-precommit-review\SKILL.md
```

Скопируйте `svn-precommit-review/SKILL.md` из этого репозитория в выбранное место.

## Использование

Проверка только для чтения:

```text
$svn-precommit-review Проверь текущие изменения SVN перед коммитом и создай корейское сообщение коммита.
```

Запрос CLI-коммита:

```text
$svn-precommit-review Проверь изменения в <SVN_WORKING_COPY>, add необходимые новые исходные файлы и после финального подтверждения выполни CLI-коммит только одобренной области.
```

После показа области и сообщения дайте один явный ответ.

```text
네, 진행해
```

## Поведение

- Проверяются `svn status --xml`, состояние удалённого репозитория, content diff и property diff.
- Проверяются сгенерированные файлы, IDE/пользовательские файлы, логи, локальная конфигурация, секреты, конфликты, отсутствующие файлы и недостаточная проверка тестами.
- При запросе CLI-коммита могут быть выполнены `svn add` для явно нужных новых исходников, файлов проектов, ресурсов и необходимой конфигурации.
- `bin`, `obj`, логи, кэш, архивы, `.env`, файлы с возможными секретами, сгенерированные и неоднозначные файлы не добавляются.
- По запросу включить проверенные кандидаты на удаление удаление планируется только для чистых versioned локальных путей.
- Не удаляются локально изменённые, конфликтующие, switched, external, locked или неоднозначные пути.
- Перед коммитом состояние и diff целей проверяются повторно; работа останавливается и повторно проверяется только при изменении одобренной области, существенного содержимого или блокирующего состояния SVN.
- Широкие `svn add`, `svn delete` и `svn commit` не используются.

## Корейское сообщение коммита

Для CLI-коммита используется временный файл сообщения UTF-8 без BOM и `--encoding UTF-8`:

```powershell
svn commit --file <message-file> --encoding UTF-8 <approved-paths>
```

Временный файл удаляется после каждой попытки. Когда доступ к репозиторию позволяет, XML-сообщение фактически созданной ревизии сравнивается с исходным. Если сохранённый корейский текст повреждён, навык сообщает о сбое проверки кодировки и не повторяет коммит и не меняет revision property.
